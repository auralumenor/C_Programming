# 🔒 Security Policy

## 📌 Supported Versions
We actively maintain the latest version of this repository.  
Security updates will only be applied to the **main branch**.

| Version   | Supported |
|-----------|------------|
| Main      | ✅ |
| Older branches | ❌ |

---

## 🛡️ Reporting a Vulnerability
If you discover a security vulnerability in this repository:

1. **Do not open a public issue.**  
   Security issues should be reported privately to protect users.

2. **Contact the Maintainer (Raman Raj):**  
   - Use GitHub’s private contact option (via repository settings).  
   - Or reach out directly through email/DM if available.

3. Provide as much detail as possible:  
   - Steps to reproduce the issue  
   - Potential impact  
   - Suggested fix (if any)

---

## ⚖️ Responsible Disclosure
We ask that you:
- Report vulnerabilities responsibly and privately.  
- Allow maintainers reasonable time to investigate and fix the issue.  
- Avoid exploiting or sharing the vulnerability before it is resolved.  

---

## ✅ Commitment
We are committed to:
- Investigating all reports promptly  
- Communicating transparently about fixes  
- Updating documentation and dependencies to maintain security  

---

Your efforts to improve the security of this project are greatly appreciated.  
Together, we make this repository safer for all learners and contributors.
