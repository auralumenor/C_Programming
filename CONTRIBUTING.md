# 🤝 Contributing Guidelines

Thank you for your interest in contributing to the **C Programming Repository**!  
This project is designed for educational purposes, and contributions help make it more useful for students learning C.

---

## 📌 How to Contribute

### 1. Fork the Repository
- Click the **Fork** button at the top right of this page.
- This will create a copy of the repository under your GitHub account.

### 2. Clone Your Fork
```sh
git clone https://github.com/your-username/C_programming.git
cd C_programming
```
### 3. Create a New Branch
Always work on a separate branch for your changes:
```sh
git checkout -b add-new-program
```

### 4. Add Your Program
- Place your .c file in the main directory (or in a relevant folder if organized later).
- Use clear, descriptive filenames (e.g., bubble_sort.c, matrix_multiplication.c).
- Add comments in your code to explain logic for beginners.

### 5. Update the Program Index
- Edit the README.md file.
- Add your program to the Program Index table with a short description.
Example:
```markdown
| `bubble_sort.c` | Implements Bubble Sort algorithm |
```

### 6. Commit Your Changes
```sh
git add .
git commit -m "Added bubble_sort.c program"
```

### 7. Push to Your Fork
```sh
git push origin add-new-program
```

### 8. Submit a Pull Request
- Go to your fork on GitHub.
- Click Compare & Pull Request.
- Provide a clear description of your changes.
---

## ✅ Contribution Checklist
Before submitting, make sure:
- [ ] Your code compiles without errors.
- [ ] You’ve added comments for clarity.
- [ ] You’ve updated the Program Index in README.md.
- [ ] Your commit message is descriptive.
---

## 📜 Code Style
- Use consistent indentation (4 spaces or tabs).
- Include meaningful variable names.
- Add comments for logic and functions.
- Keep programs simple and beginner‑friendly.
---

## 💡 Suggestions
If you don’t want to add code but have ideas:
- Open an Issue with your suggestion.
- Label it as enhancement or idea.
---

# 🙌 Thank You
Every contribution makes this repository better for learners.
Your effort helps students worldwide understand C programming more easily!
