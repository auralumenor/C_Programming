## 📂 C Programs Collection
This repository contains a variety of programs written in the **C programming language**.  
They are designed to help students grasp core concepts such as:

- Control structures (`if-else`, `switch`, loops)  
- Functions and modular programming  
- Input/output operations  
- Basic algorithms (e.g., Fibonacci series, Armstrong number, leap year check)  
- Problem-solving using structured logic  

---

## 📑 Program Index
Here’s a quick overview of the programs included:

| File Name              | Description |
|------------------------|-------------|
| `fibonacci.c`          | Prints the Fibonacci series up to a given number |
| `armstrong.c`          | Checks whether a number is an Armstrong number |
| `leap_year.c`          | Determines if a given year is a leap year |
| `factorial.c`          | Calculates the factorial of a number using loops |
| `prime_check.c`        | Checks whether a number is prime |
| `reverse_number.c`     | Reverses the digits of a number |
| `sum_digits.c`         | Finds the sum of digits of a number |
| `simple_io.c`          | Demonstrates basic input/output operations |
| `functions_demo.c`     | Example of using functions in C |

## 🚀 How to Use
1. Browse the `.c` files to explore different program examples.  
2. Compile any program using a C compiler (e.g., GCC):  
   ```sh
   gcc filename.c -o filename.exe
   ```
3. Run the compiled executable to see the output:
   ```sh
   ./filename.exe
   ```
